# Agent Prompts — logopaedie-jobs

Diese Prompts standardisieren Rollenarbeit.

## Rollen

- `planner-agent.md`: Analyse, Risiken, Fahrplan.
- `implementer-agent.md`: Umsetzung nach freigegebenem Plan.
- `reviewer-agent.md`: Review auf Bugs, Datenschutz, SEO, Tests und Git-Hygiene.

## Pflicht

Jeder Agent liest zuerst:

- `AGENTS.md`
- `PROJECT_CONTEXT.md`
- `WORKFLOW.md`
- `TESTING.md`
- `SECURITY.md`
- `docs/agents/worker-map.md`
- `docs/agents/git-workflow.md`

Reports orientieren sich an `docs/agent-reports/report-template.md`.
